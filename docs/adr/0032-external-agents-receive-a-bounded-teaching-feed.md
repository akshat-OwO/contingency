# External agents receive a bounded Teaching Feed

The external compiler agent receives a **Teaching Feed**, not the full Demonstration Trace. The feed contains user instructions, captured browser actions, Browser Snapshots, URL transitions, and screenshots with known sensitive fields masked. Known secret values become Variable references. The full Trace and video remain local, and MCP never returns cookies, authorization headers, or network bodies as Teaching input.

The feed is bounded in size as well as in content. Screenshots travel as references — id, content hash, capture time, page URL, and format — and their bytes are stored once under their content address inside the Agent Flow package. The agent fetches one image at a time with `agent_teaching_screenshot_get`, and Evidence Slices and operation-replay records hold the same references. A screenshot therefore costs a few hundred characters wherever it is projected, so the feed's size tracks how much the user demonstrated rather than the Page's resolution. Embedding the images was rejected because the one tool an external agent must call in order to propose Agent Steps became too large for that agent to read: a six-step session on a public site produced a 4.4 MB response. `agent_browser_screenshot` still answers with bytes directly, because it is one deliberate capture rather than a projection over a whole Demonstration.

This boundary is best-effort rather than a claim of complete redaction: ordinary visible page content may still be sensitive, so Agent View tells the user that Teaching Feed content goes to the selected external agent. Returning the raw Trace was rejected because it includes unredacted DOM and network payloads; prompting before every observation was rejected because it would make interactive Teaching unusable.
