# Bundled example skills have distinct authority

Contingency ships read-only Example Flow Skills that can run on the bundled demo site without claiming user verification. They have an explicit bundled origin, are labeled Example, and remain outside the user's Catalog Root. The user teaches a variation separately; that variation and its Run evidence stay clearly identified in the current catalog and follow the normal Dry Run and verification lifecycle.

Prepared task text alone cannot demonstrate Run-time private inputs and required scans, because those operations require a Flow Skill. Copying bundled skills into the user's catalog with fabricated verification would erase the meaning of user verification. Explicit support for bundled examples demonstrates every capability while keeping their authority limited to the demo site.
