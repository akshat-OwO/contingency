# Contingency

Contingency lets companies teach product sanity journeys through user-led browser demonstrations, learn a reusable Flow Skill from each one, and run those Flow Skills to monitor whether features still work.

The execution terms below reflect the accepted design in [ADR 0044](./docs/adr/0044-agents-own-flow-skill-execution.md). Task contracts and storage are defined; the current runtime still enforces Agent Steps until lifecycle, authority, assessments, and Workspace integration land in #322 through #325.

## Language

**Suite**: A named, ordered manifest of Flow Skills that defines the required sanity coverage for one business area. The first version runs members sequentially; after a member fails, the agent pauses and asks the user whether to retry it, continue, or stop. An agent may suggest changes to a Suite, but it may not infer that an unlisted Flow Skill is required or claim complete coverage without running every listed Flow Skill. Suites are not built yet; see `docs/future/agent-flow.md`. _Avoid_: vertical (as the persisted artifact), inferred coverage, test bucket

**Teaching**: The authoring process in which a user performs a journey in the browser while Contingency records it. An agent may prepare the browser during setup, then hands control to the user before **Start recording**. Nothing is captured before Start, and every capture source ends at **Stop**. During recording, the agent observes and learns afterward; the user may relay Instructions at branch points. Teaching produces a Teaching Recording, not a reusable artifact. _Avoid_: mixed control during recording, Replay, autonomous Run, compilation

**Teaching Recording**: The temporary, process-independent bundle one recording produces under `.contingency/.recordings/<recording-id>/`: a manifest, video, Trace, and a bounded semantic event stream of actions, accessibility targets, URL transitions, and user Instructions. It is sensitive learning evidence, not reusable automation, and it outlives its creating process only until the user verifies the Flow Skill learned from it. _Avoid_: Demonstration (superseded), Flow Skill, screen recording (as the product artifact)

**Instruction**: Free text the user relays while recording — for example why an optional popup should be skipped. Instructions join the Teaching Recording's event stream in order, so a learning agent reads each one beside the actions it explains. _Avoid_: side-comment (as the domain term), annotation, prompt

**Teaching Timeline**: The bounded, best-effort-redacted projection of a claimed Teaching Recording available to the external agent, returned one explicit page at a time. It carries semantic actions with the accessibility evidence on each side of them, Instructions, URL transitions, and keyframe references — never keyframe bytes, and never the raw Trace or the whole video. Secret values appear as Variable references. _Avoid_: Teaching Feed (superseded), Trace, raw browser export, guaranteed-redacted artifact

**Flow Skill**: The one durable authoring artifact: a directory at `.contingency/<flow-name>/` holding `SKILL.md` plus optional `references/`. `SKILL.md` is a how-to with frontmatter naming the skill, its description, and its declared inputs, and a numbered procedure whose every step ends in a `Done when:` outcome a later run can check. Its frontmatter also carries the hosts the demonstration visited and the Emulation it ran under, stamped by Contingency rather than authored by the agent, because the Teaching Recording that proves them is deleted once the user verifies. It carries no revisions, no approval heads, and no captured media. Contingency validates its shape but does not grade its prose. _Avoid_: Agent Flow (superseded), Flow, generated to-do list, raw Trace

**Agent Step**: The historical execution unit that bound a Run to one numbered instruction and its assessment. New Runs have no Agent Steps; numbered instructions remain part of the Flow Skill's written procedure. _Avoid_: current Run progress, captured action, generated to-do item

**Confirmation**: The user's authorization for one irreversible or high-impact browser action attempt. Retrying the action requires fresh Confirmation; the requested task authorizes exploration and recovery, while an unrelated task requires separate user authorization. _Avoid_: Confirmation Step (superseded), ordinary click confirmation, model warning

**Verified Flow Skill**: A Flow Skill the user has explicitly verified in the Workspace after a passing Dry Run. Verification is the only gesture that authorizes deleting the Teaching Recording, and it is what makes the Flow Skill reusable for later Runs. Rejection returns the Flow Skill to drafted and keeps every Teaching artifact for another edit. _Avoid_: Approved Agent Flow (superseded), trusted recording, published Run

**Dry Run**: A complete attempt to demonstrate a drafted Flow Skill's intended outcome in a fresh browser context under its saved Teaching Emulation, with fresh inputs supplied when needed. The agent chooses its route and reports an evidence-backed Agent Assessment; a partial attempt or an attempt with Takeover cannot pass, and a pass keeps Teaching evidence until user verification. _Avoid_: Verification Run (superseded), Teaching continuation, same-context retry, Replay

**Catalog Root**: The explicitly selected directory that bounds Flow Skill discovery, Teaching Recording storage, and Run evidence. It defaults to the current workspace's `.contingency` directory; an agent never searches a user-global catalog implicitly. Its Flow Skill directories are shared source and may be committed; its `.recordings/` and `agent-runs/` contents are local and ignored. _Avoid_: global catalog, home directory scan, issue repository, Agent Flow Catalog (superseded)

**Execution Boundary**: The Runner-enforced Domain Scope and user-confirmation requirement for irreversible browser actions during an Interactive Run or a Dry Run. A Dry Run's Domain Scope is the hosts its Teaching Recording visited. A pause surfaces as a Pending Decision the user allows or refuses in the MCP conversation; the Workspace mirrors it read-only. The external agent controls its plan within this boundary; Contingency does not require its to-do list or browser actions to repeat the demonstrated action path. _Avoid_: generated to-do list, model prompt, Agent Assessment

**Domain Scope**: The exact hosts and explicit wildcard patterns a session may visit without pausing, including declared hosts of Flow Skills the user requests during an Interactive Run or its starting host when no skill supplies a scope. It governs top-level navigation, requires intervention for an unapproved host, and excludes embedded subframes; a Dry Run uses its Teaching Recording's hosts. _Avoid_: every linked domain, implicit redirect permission, global allowlist, embedded frame policy

**Takeover**: The exclusive interval in an Interactive Run or a Dry Run when the user controls the browser and agent action tools are disabled. User initiation interrupts the in-flight agent action and takes priority, though an action already dispatched to the browser cannot be undone. Capture continues, sensitive inputs become Variable references rather than literals, and the user explicitly returns control to the agent. Takeover is not available during Teaching, which is user-led throughout, and a Dry Run that had one cannot pass. _Avoid_: concurrent control, paused capture, session transfer, mixed-control Teaching

**Action Window**: The span of one agent browser action in an Interactive Run or a Dry Run, from dispatch until the Page settles, padded briefly on each side so a watcher sees the approach and the result. Each Action Window plays at real speed in the Run's video, with the agent's cursor drawn in. _Avoid_: step, Agent Step, tool call

**Idle Gap**: Any span of an Interactive Run or a Dry Run outside every Action Window and every Takeover, such as agent thinking or a wait on a Pending Decision. The Run's video fast-forwards Idle Gaps and marks each one as fast-forwarded on screen. _Avoid_: pause, dead time, thinking time (as the domain term)

**Browser Snapshot**: A compact accessibility representation of the current Page with short-lived element references for agent actions. References expire after navigation or meaningful page mutation; screenshots remain a separate visual observation. _Avoid_: screenshot, Trace, DOM dump

**Interactive Run**: An agent-controlled attempt at a user-requested task, connected to a live MCP conversation, with optional verified Flow Skills sharing one browser context and its starting Emulation. The user may redirect the task, and failures leave the browser available for investigation until explicit completion, user closure, or process exit; required intervention still pauses execution. _Avoid_: one Flow Skill execution, live Teaching, autonomous Run

**Suite Setup**: The optional Flow Skill a Suite runs once to establish browser storage such as an authenticated session. Each Suite member then receives that state in a fresh isolated browser context, and the in-memory state is discarded when the Suite Run ends. A failed or inconclusive Suite Setup stops member execution and leaves Suite coverage incomplete. _Avoid_: shared Suite browser, persisted login profile, Suite member

**Workspace**: The single local web interface for Teaching, agent-controlled Runs, and Run Summary inspection. It shows the live browser under a floating dock that carries the Teaching state and the one action that state offers, and exposes browser setup tooling such as Emulation and storage inspection. A Workspace-opened Teaching session starts with user control; an agent-opened Teaching session may start with agent control during setup. The user controls the browser during recording and may Takeover during an Interactive Run. _Avoid_: Create View, Audit View, agent conversation

**Agent Session**: The ephemeral coordination envelope owned by one MCP server process that binds one Workspace, browser, and external agent to at most one active Teaching or Run activity. It dies with its process; the Teaching Recording and the Run outlive it. It is not reusable automation. _Avoid_: Run, Flow Skill, browser profile

**Agent Assessment**: The agent's evidence-backed conclusion about the requested task in an Interactive Run or the Flow Skill's intended outcome in a Dry Run: `working`, `not-working`, `inconclusive`, or `blocked`. It is a model judgment with an explanation and supporting evidence, rather than a result derived from numbered instructions. _Avoid_: step assessment, assertion, verified result, Regression

**Run Summary**: The local Workspace report of a Run's requested task, changed instructions, Agent Assessment, evidence-backed findings, execution outcome, and browser evidence. Historical summaries retain their step assessments; a Dry Run's summary remains Teaching evidence subject to Cleanup. _Avoid_: agent plan, step coverage, Trace, Handoff, uploaded report

**Cleanup**: The verify-then-purge sequence that deletes a Teaching Recording's video, Trace, events, and keyframes, together with the evidence of its Dry Runs, once the user verifies the Flow Skill learned from it. Cleanup is idempotent and resumes at startup, and a cleanup failure never rolls back the verified Flow Skill: the Workspace names the retained sensitive files and offers a retry. After cleanup only the Flow Skill and its references remain. _Avoid_: Artifact Retention (superseded), Flow Skill deletion, catalog archival, Variable lifetime

**Variable**: A named value declared by a Flow Skill and supplied when needed, scoped to that skill so equally named inputs in different skills can differ. Its independent `secret` and `runtime` properties describe redaction and interactive prompting; a 2FA code is both, while a target environment URL is neither. _Avoid_: Secret Variable (superseded), environment variable, captured secret, redacted value

**Emulation**: The coherent browser device and environment one session runs under, recorded with a Teaching Recording and reproduced by its Dry Run. It covers viewport, browser identity, geolocation, website permission decisions, locale, timezone, and color scheme. Coordinates and permission are independent: a site receives the emulated location only when the session grants it access, and observes denial when the session denies it. _Avoid_: device profile, override, spoofing

**Trace**: The local per-session artifact recording each action's before and after state, DOM snapshot, timing, network, and console. It supports inspection. Unredacted, and therefore sensitive. It never reaches an agent, and a verified Flow Skill leaves none behind. _Avoid_: log, replay (as a synonym for Trace)
